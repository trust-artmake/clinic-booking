🗓 毎日やること

毎朝（開店前）

  1. 管理画面を開く
  2. ホーム画面 を表示
  3. 「今日の予約件数」「要対応」「次の予約」を見る
  4. 要対応が 0以上 だったら、顧客カルテタブで内容を確認する

毎晩（閉店前）

  1. 予約管理タブ で「今日」を選ぶ
  2. 「✅ 来店済み」を押し忘れている予約がないかチェック
  3. 無断キャンセルがあれば「⚠️ 無断」で記録
  4. 「要対応」が残っていれば、対応してから「対応完了」にする（「✅ 対応完了にする」の方法A/B）

🏠 ホーム画面で見る場所

ホームには3つのカードが並びます。

① 📋 今日やること

  • 左の数字：今日の予約の合計件数
  • 真ん中（赤）：要対応のお客様の人数。0より大きければ優先
  • 「次の予約：○○ 様」：これから来るお客様の時刻と名前

② ⚡ よく使う入口

  • 「📋 予約管理」：今日の予約一覧へ
  • 「🗂 顧客カルテ」：お客様の情報・履歴を見る
  • 「🌐 予約入口を開く」：お客様用のLINE予約入口を別タブで確認

③ 📈 売上ハイライト（任意）

  • 今月の予約数・来店数の小さな数字が出ます。閉店前のチェックに使えます。

📅 今日の予約を見る

開き方

  • ホームの 「📋 予約管理」 ボタン、または上の 「予約・顧客」 タブ

期間タブ

  • 📅 今日 … 今日の予約だけ
  • 今週 … 今週分
  • 今後すべて … 未来の予約全部

普段は 「今日」 タブで作業します。 「あの予約どこ？」となったら 「今後すべて」 に切り替え。

予約カードの見方

場所意味
左上の時刻予約の開始〜終了時間
右上のバッジ🆕新規 / 🔁○回目（リピート回数）
「📋問診済み」「⏳問診 未記入」問診の状況
「✅来店済み」「⚠️無断キャンセル」来店結果
「📞電話予約」電話で受けて手入力した予約（LINE連携なし＝問診・同意書はLINEで送れません）

絞り込み

  • アーティスト：担当者ごとに絞り込み
  • 問診ステータス：「問診：未記入」を選ぶと 問診リマインドを送るべき人だけ が出る

お客様一覧の「📅 予約あり」

  • 顧客カルテ タブの一覧で 「📅 予約あり」 のチップを押すと、今後の予約がある人だけ に絞れます（過去の予約だけの人・キャンセル済みは含みません）
  • 該当する人のカードには 「📅 次回 9/10 14:30」 のように次回の日時が付きます

⚠️ 要対応のお客様に返信する

「要対応」とは

お客様がLINEで「担当者に聞きたい」「不安なんです」と送ってきたとき、AIが自動で「スタッフが確認します」と答えて、このリストに名前が上がります。

このとき AI の自動返信は止まっています。 スタッフが直接 LINE で返信するか、電話で対応してください。

一覧の開き方

  • ホームの 「要対応を見る」 ボタン、または 顧客カルテ タブ → 「要対応」フィルターをタップ

お客様カルテ内の確認

  • カルテの上のほうに 「⚠️ 有人対応中：○○（理由）」 が出ます
  • 来店回数、最終来店日、累計利用額もここで見られます
  • 過去のメモ・対応履歴も時系列で表示されます

LINEへの返信

LINE公式アカウントから普通にスタッフが返信してください。

「💬 受信箱」タブについて（試験運用中）

  • 管理画面に「💬 受信箱」タブがありますが、店舗ごとに順番に有効化している 試験運用中の機能 です。
  • 「この店舗では受信箱がまだ有効ではありません。」と出る店舗は、これまで通り LINE公式アカウントから返信してください。
  • 有効な店舗でも、返信欄に 「（モック・外部LINE送信なし）」 と出ている間は、送っても お客様には届きません（練習用の送信）。送信後に「モック送信完了：外部LINEには送っていません。」と出たら、実際の返信は LINE公式アカウントから行ってください。
  • 受信箱が本番の返信に使えるようになったら、管理者から改めて案内します。

✅ 対応完了にする（AI 返信が再開）

⚠️ この操作が一番大切です。 対応が終わったら 必ずその日のうちに「対応完了」 にしてください。 しないと、AIがそのお客様にずっと返信しない状態が続きます。

❗ お客様カルテの「有人対応」欄からは変更できません。 カルテの「✏️ メモ・区分・有人対応の更新」パネルは、メモ・区分・理由を書くだけの場所です（有人対応の欄は表示のみ。「理由」は要対応の間だけ保存されます）。対応完了は、下の どちらか の方法で行います。

方法A：スタッフグループLINEで「完了」を送る（受信箱を使っていない店舗の基本の方法）

  1. 要対応になったとき、スタッフグループLINE に 「🔔 対応をお願いします #12」 のような通知が届いています（#の数字がお客様ごとの対応番号）
  2. その通知の中の 「完了 12 」 の行をコピーする
  3. 末尾に自分の名前を付けて、スタッフグループLINEに送信（例：完了 12 佐藤）
  4. 「対応番号 12 … を対応完了にしました。」 の返事が来れば完了
  5. 返事が 「この完了操作は管理画面の受信箱へ移行しました。…」 だった店舗は、受信箱の運用に切り替わっています → 方法B で行ってください
  6. 返事が 「対応完了にできませんでした。…」 のときは 完了していません（要対応バッジが残ります）。受信箱が使える店舗は受信箱で新着や送信状態を確認し、使えない店舗はオーナーに連絡してください
  7. 返事が まったく来ない ときは、自分がスタッフとして登録されているか（名前の付け方が正しいか）をオーナーに確認してください

方法B：「💬 受信箱」の「対応完了（AI再開）」ボタン（受信箱が有効な店舗）

  1. 管理画面の 「💬 受信箱」 タブで、そのお客様の会話を開く
  2. まだ対応を始めていなければ 「対応を始める」 を押す
  3. 対応が終わったら 「対応完了（AI再開）」 を押す
  4. 確認画面「対応を完了すると、次回のお客様メッセージからAI対応を再開します。対応完了にしますか？」→ 「OK」
  5. 「この店舗では受信箱がまだ有効ではありません。」と出る店舗では 方法Aを使ってください
  6. 要対応なのに受信箱に会話が見当たらない（ボタンが出ない）お客様は、オーナーに連絡してください

完了したあとに何が起きるか

  • カルテの「要対応」バッジが消える
  • AI がそのお客様に自動返信できる状態に戻る ✅
  • ホームの「要対応」カウントが −1 される

注意

  • 「要対応（AI停止・スタッフ対応中）」のまま残すと ずっと AI が止まったまま です
  • 必ずその日のうちに「対応完了」へ。方法A・Bどちらでもできない時は、管理者（オーナー）に連絡してください

🗂 お客様カルテを見る

入り方

  • 顧客カルテ タブ → 検索ボックスにお名前 or LINE名 → 名前をタップ

画面に出る内容

  • 上：お名前・来店回数・累計利用額・最終来店日
  • 📝 同意書（電子署名）：署名済みなら日付＋写真使用可否
  • 📋 事前問診票：アレルギーなど問診内容
  • 背景メモ：スタッフが残した対応メモの累積
  • 来店・対応履歴：時系列のタイムライン

メモを追記する

  1. 下部 「背景メモに追記」 に一言書く
  2. 「この内容で更新する」 を押す
  3. 自動で日付が付いて、既存メモは消えずに追加される

⭐ 口コミを見る・追加する

入り方

予約・顧客 → ⭐ 口コミ

追加する時

  1. Googleの本物の口コミをコピー
  2. 担当・評価・本文を入れる
  3. 「＋ 追加して公開」 を押す

注意

  • 追加すると公開されます
  • 削除は戻せないので、迷ったら管理者に確認してください

📨 問診を送る

いつ送る？

予約カードに 「⏳問診 未記入」 が出ているお客様で、来店までまだ時間がある とき。

手順

  1. 予約カード内の 「📨 問診リマインド」 ボタンを押す
  2. 「このお客様に問診リマインドをLINEで送信しますか？」が出る
  3. 「OK」 を押す
  4. お客様のLINEに問診フォームのリンクが届く

送れない時

  • 「LINEと連携していないため送れませんでした」 → 電話予約のお客様は送れません。来店時に紙の問診を渡してください。

📝 同意書を送る

いつ送る？

初来店 のお客様で、来店の 数日前 に送るとスムーズ（署名はスマホで完結）。

手順

  1. 予約カード内の 「📝 同意書を送る」 ボタンを押す
  2. 「施術同意書の記入リンクをLINEで送信しますか？」が出る
  3. 「OK」 を押す
  4. お客様のLINEに電子同意書リンクが届く
  5. お客様が署名すると、カルテに 「✅ 署名済み」 が表示される
  6. 署名済みの同意書は、予約カードの 「📄 PDFを開く」 で中身を確認できる

送れない時

  • 電話予約のお客様はLINE連携がないため送れません。紙の同意書 を来店時に使ってください。

✅ 来店を記録する

来店済み

  1. 予約カード内の 「✅ 来店済み」 ボタンを押す
  2. 確認画面で 「OK」
  3. カードに「✅来店済み」バッジ
  4. カルテの 来店回数・累計利用額が自動で更新 される

無断キャンセル

  1. 「⚠️ 無断」 ボタンを押す
  2. 「OK」
  3. カードに「⚠️無断キャンセル」バッジ

料金について

来店済みを押すと メニューの料金が累計に加算 されます。 特別な金額調整が必要な場合は、オーナー・管理者に伝えてください。

🔄 予約変更・キャンセル対応

「日時を変えたい」と連絡がきた

✅ キャンセルして作り直さないでください。 予約カードの 「🗓 日時を変更」 を使うと、同じ予約のまま日時だけ変わるので、問診票・同意書・カレンダーの予定がそのまま残ります。

  1. お客様から希望の新しい日時を聞く
  2. 予約カードの 「🗓 日時を変更」 ボタンを押す
  3. 新しい 日付と時刻 を選ぶ（担当・メニューはこの画面では変えられません）
  4. 「お客様とスタッフグループへ変更のお知らせをLINEで送る」 のチェックを確認する
    • チェックあり → お客様（LINE予約の方）とスタッフグループに変更のお知らせが届く
    • 電話でお客様に伝え済みのときはチェックを外す（1通も送りません）
  5. 「この日時に変更する」 → 確認画面で変更前・変更後・LINEを送るかを見て 「OK」
  6. 画面が閉じて一覧が更新されれば完了（成功のメッセージは出ません）

うまくいかない時

  • 「その担当者は、その時間に別のご予約が入っています」→ 別の時間を選ぶ
  • 「🗓 日時を変更」ボタンが出ない → すでに「✅来店済み」「⚠️無断キャンセル」を記録した予約は変更できません。新しい予約として 「📞 ＋ 電話予約を登録する」 で作ってください
  • 担当やメニューも変えたい → 「❌ キャンセル」してから「📞 ＋ 電話予約を登録する」で作り直す（この場合は問診票・同意書のひも付けが切れます）

「キャンセルしたい」と連絡がきた

  1. 予約カードの 「❌ キャンセル」 ボタン
  2. 確認画面：「この予約をキャンセルしますか？カレンダーの枠も解放します。（お客様への自動連絡はしません）」
  3. 「OK」
  4. お客様への自動連絡はシステムから送られない ので、LINEか電話で一言伝えてください

電話で予約を受けた

  1. 「📞 ＋ 電話予約を登録する」 ボタンを押す
  2. お客様名・フリガナ・電話番号を入力
  3. 担当アーティスト を選ぶ（先に選ばないとメニューが出ません）
  4. メニュー・新規/リタッチ・日時を選ぶ
  5. 「登録する」

🚫 絶対にやってはいけないこと

スタッフ画面に最初から「触れる導線がない」もの

安心してください。スタッフ権限では そもそも画面に出ません。

  • LINE接続（鍵の登録） … 設定タブの「LINE接続」パネルは表示されません
  • スタッフの追加・削除・パスワード発行 … 「ユーザー管理」タブは管理者のみ
  • メニュー・料金の変更 … 編集用のボタンは表示されません
  • アーティストの情報・担当メニューの変更 … 編集用のボタンは表示されません
  • 初期設定の本番開始ボタン … 表示されません

スタッフが気をつけること（誤操作防止）

⚠️注意
❌ キャンセル ボタン「OK」を押したら取り消せない。日時と名前を声に出して確認してから押す
⚠️ 無断 ボタン同様に取り消し不可。本当に無断か確認してから押す
「この内容で更新する」メモ・区分・理由だけが保存される（有人対応の状態はここでは変わらない）
受信箱の「対応完了（AI再開）」押すとAIが返信を再開する。お客様への返信が本当に終わってから押す
キャンセル後お客様へ自動連絡されない。LINE or 電話で必ず一言 伝える

困った時の最後の連絡先：オーナー（システム管理者）まで。画面のスクショを撮って一緒に送ると早く解決します。
