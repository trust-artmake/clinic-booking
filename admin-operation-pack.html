📅 カレンダー表示・自分の予約

スマホの戻る（左からのスワイプ）で1つ前の画面に戻れます。書きかけのときは確認が出ます。「書き続ける」で入力を保ち、「戻る（書いた内容を消す）」で戻ります。

チャットは、LINEでつながっている友だちを最後のメッセージが新しい順に表示します。メッセージがない人は友だち追加日順です。名前の丸・最後のひとこと・時刻・赤い未読の印で相手を探せます。「AI：」「店：」は最後に送った側です。要返信・対応中・送信失敗・ブロックは小さな札で表示します。

上の店舗選択と「名前で探す」で絞り込めます。入力して少し待つと検索し、「もっと見る」で続きを読み込みます。名前検索では、開いている会話と返信の書きかけは残ります。店が未設定のお客様は、テナント管理者・全体管理者だけが全店舗表示で閲覧できます。

会話はお客様が左の白、スタッフが右の緑、AIが右の薄い緑の吹き出しです。日付ごとに区切り、画像は「画像」と表示します。丸は名前の頭文字で、顔写真は今後の対応です。

対応ステータス（ラベル）はお客様1人につき1つです。会話の「対応ステータス」、一覧の「ステータスを変更」、カルテから付け替えられます。ラベルを変えてもAIの停止・再開は変わりません。店舗を選ぶとステータスで一覧を絞れます。

店の管理者・全体管理者は「ラベル設定」で追加・名前・色・並び順・有効/無効を変更できます。予約用の4つは名前と色を変えられますが、無効にできません。無効なラベルは新たに選べません。付与済みのラベルは「（無効）」を付けて残します。

自動付け替えは予約用の4つだけです。予約作成で初回/リタッチ予約確定、取消で予約未定、来店済みで次の予約がなければリタッチ予約未定になります。次の予約があればそちらを優先します。手で選んだラベル（予約用の4つ・ラベルなしも含む）は保持します。「予約に合わせる」を押すと自動付け替えへ戻ります。別の更新があった場合は最新のラベルを確認して選び直してください。

チャットはいつでも送れます。送るとAIはお休みになり、再開は管理者の「対応完了（AI再開）」です。 返信機能が有効で権限があれば、AI対応中・対応完了・まだやり取りのない友だちにも「返信を送る」で先に送れます。宛先と本文、AIがお休みになる注意を確認して送信してください。送信と同時に自分が担当の「対応中」になり、すでに別のスタッフが対応中なら担当は変わりません。送信に失敗しても「対応中」とAI停止は残ります。ブロック中・LINEでつながっていないお客様には送れません。管理画面からの送信はLINEの月間送信数を使います。

会話を開くだけでは未確認のままです。上部右の緑の「未確認 ✉」（赤い丸つき）を押すと「確認済み ✓」になり、一覧の未読の印も消えます。「確認済み ✓」を押すと未確認に戻せます。状態はスタッフ全員で共有します。確認画面は出ません。機能が無効、会話状態や受信履歴がない場合はボタンが出ません。競合が出たら会話を開き直してください。

チャットの「カルテを見る」で同じお客様のカルテへ、「次の予約」で予約シートへ移動できます。返信の書きかけがあるときは「移動する（書いた内容を消す）／書き続ける」で選びます。

カルテの「チャットで見る」で同じ会話へ、予約履歴（取消済みを除く）から予約シートへ移動できます。「← ○○に戻る」またはスマホの戻るで元の画面へ戻れます。

ホームの「要対応を見る」はチャット（無効な場合はカルテ一覧）へ、「次の予約」は予約シートへ移動します。

  1. 予約・顧客 → 予約管理は月表示で開きます。月曜始まりで、今日の曜日の列に薄い色が付きます。一覧／日／週／月で切り替え、前へ／今日／次へで移動します。週は基準日から7日間、スマホでは日ごとの縦リストです。
  2. 月のマスには担当色の帯で名前・新規／リタッチ・金額が出ます。予約は最大5行で、残りは +N。0円は「済」、先払い済みの会計は「支払い済み」、メニュー・コースがリタッチ／2回目／2回セットの0円予約は「2回目 支払い済み」（月の帯は「2回目済」）です。有料の初回でメニュー名などから確認できる2回セットは「(2回セット)」を付けます。
  3. 日付 → その日の一覧 → 予約の順に押します。日別一覧には開始〜終了、担当の頭文字、📝施術メモあり・✓来店済み・¥会計済みが出ます。会計開始日以降の来店済み予約で会計が未入力なら赤い点が付きます。＋ 電話予約はその日を入力した既存フォームを開きます。
  4. 予約シート上部の📌「前回の次回やること」、注意事項と前回のメモ（新しい順3件）を確認し、施術メモに色 → 技法 → 形 → 次回やること → 自由メモの順で、入れたい欄だけ入力して施術メモを保存を押します。全部空でも保存できます。色は自由入力（100文字まで）で、色ボタンを押すと「＋」で足されます。技法（毛並み／パウダー／ミックス）・形（平行／アーチ／平行アーチ／自眉に沿って）は、同じチップをもう一度押すと解除できます。「次回やること」は500文字まで、「自由メモ」は2000文字までです。左右差・濃さ・混ぜ方などの補足は自由メモへ。保存結果の確認メッセージまで見てください。編集は上書きで、前の本文は残りません。取得失敗時は開き直してください。
  5. 予約シートの来店済み・会計・日時変更・キャンセル・カルテは既存の操作です。会計は会計開始済み店舗の来店済み予約で権限のある人に表示されます。来店済み／無断の予約には日時変更が出ません。閉じる ×でシートを閉じます。取消済みはカレンダーに出ません。
  6. カルテ → 施術メモで日付・担当・メニューとメモの全件を新しい順に確認できます。メモは同じ店舗・同じテナント内だけで照合し、LINE ID、電話番号、名前の順で判断します。色・技法・形・次回やること・自由メモを表示し、古いメモの左右差・濃さも残します。直近の「次回やること」は次の予約シート上部に出ます。名前だけ一致するメモと申し送りは、別の方の可能性を示す注意つきで折りたたまれます。日時も確認してください。
  7. お店の設定 → メニューとアーティスト → アーティスト → 編集 → カレンダーの色で10色または自動を選んで保存します。編集権限は既存のアーティスト設定と同じです。
  8. ログインに担当アーティストが設定されていれば最初だけ自分に絞ります。全員を表示で解除できます。担当・店舗・問診の絞り込みは一覧と共通です。休み・不在も担当の絞り込みに合わせて表示します。

休み・不在の入れ方

入れる前に、お客様が予約できる時間がいくつ減るかが出ます。用事は出勤のはじめか終わりに寄せると減りにくいです。

  1. 月の日付 → ＋ 休み・不在を押し、担当・開始日・終了日を選びます。自分の担当が設定されていれば初期値になります。
  2. 終日なら終了日を含む各日の日本時間0時〜翌0時です。時間を指定するときは「終日」を外し、開始・終了時刻を入力します。日・月をまたぐ不在も最長31日まで登録でき、メモは任意で50文字まで（例：久留米出張）。
  3. 休み・不在を保存し、保存確認を見ます。予約ページではその担当の指定時間だけ選べなくなります。既存予約と重なったら件数と時刻を警告しますが、予約はそのまま残ります。お客様名は警告に出しません。
  4. 月では予約より上の濃い帯、日別一覧では予約より上、週・日では斜線で表示します。複数日の休みは各日に同じ帯を表示します。日別一覧の休みを押して削除を確認すると、他の予約・シフトが塞いでいなければ空き枠に戻ります。
  5. シフトとの違い：休み・不在は指定した区間だけを塞ぎます。シフトは出勤時間を決める設定で、1件でも設定した担当は、ルールのない日も予約不可になります。シフト未使用の担当に単発の休みを入れるときは、この「休み・不在」を使います。
  6. 電話予約・日時変更は、休みと重なると保存前に警告します。スタッフの判断で続行できます。取得失敗の場合も確認できなかった旨を表示します。休みの保存後に再取得が失敗したら、再登録せず閉じて再読込してください。

担当アーティストの結びつけ

  1. お店の設定 → スタッフで、対象スタッフの担当アーティストを選び、担当を保存を押します。
  2. 解除はなしを選んで保存します。保存後の表示確認が済むと完了メッセージが出ます。本人の初回表示には次のログインから反映されます。
  3. 同じテナント・対象スタッフと同じ店舗の担当を選びます。同じ担当を複数の有効なスタッフに設定できません。担当が付いたまま店舗を変える場合は、先に担当を「なし」にします。
  4. 管理者は自分の店のスタッフだけ設定できます。オーナーの設定はオーナーか全体管理者が行います。店舗制限のあるオーナーはその店だけです。操作できない行には担当の選択欄が出ません。
  5. スタッフを無効にするとき（退職・停止）は、先に担当を「なし」にしてから無効にします。

💉 メニュー変更

一覧を開く

お店の設定 → メニューとアーティスト → 💉 メニュー・料金

編集する

  1. 変えたいメニューの 「✏️ 設定を変更」 を押す
  2. 編集できる項目：
    • メニュー名
    • 通常料金 / モニター料金
    • 所要時間（新規 / リタッチ）
    • 表示順（小さい数字ほど上に表示・空欄は最後）
    • 有効 / 無効
  3. 「💾 保存」 を押す → 「✅ 保存しました」が出れば完了

表示順のコツ

  • 表示順は 管理画面の一覧・お客様の予約ページ・AIのメニュー案内 の3か所に、保存した直後から同じ順で反映されます（予約ページをすでに開いているお客様には、開き直すと反映されます）。
  • 「1・2・3…」のように メニューごとに別の数字 を付けてください。同じ数字を複数に付けると、画面によって並びが少し変わることがあります。
  • 空欄のメニューは最後に回ります。新しく追加したメニューが上に来てしまう時は、ここで数字を入れて直します。

追加する

  1. 一覧下部の 「＋ 新規メニューを追加」 を開く
  2. 名前・料金・所要時間を入力
  3. 「＋ 追加」 を押す
  4. 追加後は アーティスト タブで担当を割り当てる（やらないと予約ページに出てきません）

非表示にする・削除する

  • 一時的に外す → 編集して 「有効」のチェックを外す → 「💾 保存」
  • 完全に消す → 「🗑 削除」（予約や担当割り当てで使用中は削除できません）

👩‍⚕️ アーティスト変更

一覧を開く

お店の設定 → メニューとアーティスト → 👩‍⚕️ アーティスト

編集する

  1. 対象アーティストの 「✏️ 設定を変更」
  2. 編集項目：
    • 表示名（「漢字（ローマ字）」推奨。例：「大下（maho）」）
    • 自己紹介
    • 公開 / 非公開
  3. 「💾 保存」

担当できるメニューと施術時間を設定する

編集欄の下のほうの 「担当できるメニューと施術時間」 で：

  1. このアーティストが施術できるメニューにチェック
  2. 新規 / リタッチの所要時間（分）を入力。空欄なら60分
  3. 「💾 担当メニューを保存」

💡 担当メニューが1件も紐付いていないアーティストは、予約ページに出てきません。

追加する

  1. 一覧下部の 「＋ 新規アーティストを追加」
  2. 名前を入力 → 「＋ 追加」
  3. 追加後、写真と担当メニューを設定する（次項）

プロフィール写真を変更する

  1. 編集欄を開く
  2. 「📷 写真を選ぶ」 → 端末の画像選択が開く
  3. 自動で縮小されてアップロードされる
  4. 「✅ 写真を更新しました」 → 予約ページに即反映
  5. 消したいときは 「🗑 消す」（写真がある時だけ出ます）

停止する（予約ページから外す）

編集欄の 「停止する」 を押す → 予約ページから消える。再開も同じボタン。

🗓 シフト変更（カレンダー化済み）

シフト編集を開く

お店の設定 → メニューとアーティスト → 🗓 シフト → 対象アーティストの 「🗓 シフトを編集」

① 基本シフト（曜日パターン）

画面上部の表で曜日ごとに設定：

  • 列：曜日 / 休 / 区間1 / 区間2
  • 「休」 にチェック → その曜日はまるごと予約不可
  • 区間は 「09:00〜12:00 / 14:00〜18:00」 のように 昼休みを空ける 使い方ができる（昼休みの時間帯は予約に出ない）
  • ⚠️ このアーティストのシフトを1つでも登録している場合、何も入れない曜日は「まるごと予約不可」になります

（2026-08-04 変更。以前は「受付時間内ずっと予約可」でした。休みのつもりの日に予約が入る事故を防ぐため、安全側に変わりました）

  • 「💾 基本シフトを保存」

📌 2026-08-04 に変わったこと（重要）

それまでシフトは「管理画面で見るだけ」で、お客様の予約ページには反映されていませんでした。 現在は、ここで設定した時間だけ予約を受け付けます。

判定は、そのアーティストにシフトが1件でも残っているかどうかで変わります。

そのアーティストのシフト予約ページの動き
1件でも残っている登録した時間だけ予約可。ルールを入れていない曜日・日は終日予約不可
1件も無い従来どおり制限なし（お店の受付時間ぜんぶ予約可）。久留米はこの状態
  • つまり「シフトが1件でも残っている間は、入れ忘れた日に予約が入らない」ということです
  • カレンダーで 「休（未設定）」 と出ている日が、それに当たります
  • 全部消して0件に戻せば、制限も解除されます

② 月カレンダーで特定日の例外を設定する

基本シフトの下にカレンダー：

  • ◀ 前月 / 今月 / 翌月 ▶ で月を切り替え
  • セルの色：
    • 白＝曜日パターン通り
    • 薄黄（「例外」バッジ）＝例外日が登録済み
    • 薄赤＝休み
  • 日付セルをタップ → ポップアップが開く
  • 「休み」にチェック → その日だけ休み
  • または時刻を入力 → その日だけ特別な時間
  • 「💾 この日を保存」

③ 曜日パターンに戻す

日付ポップアップ内の 「🔁 曜日パターンに戻す」 → その日の例外を消して基本シフトに戻る

④ 未保存のまま画面を離れようとした場合

「未保存のシフトがあります。破棄しますか？」 の確認が出る。「移動する（書いた内容を消す）」で進み、「書き続ける」で入力に戻ります。

🖼 症例写真の追加・公開承認（管理者のみ）

追加する

  1. お店の設定 → アーティスト → 対象の 「✏️ 設定を変更」
  2. 編集欄下部の 「症例写真」 セクション
  3. 「📷 症例写真を追加」 → 画像を選択（JPEG/PNG/WebP・5MBまで）
  4. アップロード完了後は 「未承認」 状態で一覧に出ます

承認して公開する

  • 未承認写真の 「✅ 公開する」 を押す → 予約ページの症例ギャラリーに即反映
  • 元に戻すには 「🙈 非公開にする」

削除する

「🗑 削除」 → ストレージからも削除されます（戻せません）

⚠️ 「アップロードしただけでは非公開」。必ず「公開する」を押すまでお客様には見えません。

🆘 トラブル対応

「要対応」のお客様への対応

  1. 顧客カルテ → 「要対応」 フィルタ でお客様を確認し、LINE公式アカウントから返信する
  2. 対応完了は次のどれか（成功するとAIが再開。スタッフLINEでは取得できた操作者名がグループの返事に残ります。専用の操作履歴DBへの記録はありません）
    • スタッフグループLINE に届いた「🔔 対応をお願いします #番号」通知の 「✅ 対応完了にする」 ボタンを押し、「✅ 3番 ○○様 対応完了（AI再開）」 の返事を確認する。従来の 「完了 番号 名前」 も使えます（毎朝まとめにはボタンなし）
    • 顧客カルテ の「✏️ メモ・区分・有人対応の更新」で有人対応を 「対応完了（AI再開）」 にして 「この内容で更新する」（スタッフも使える。グループLINEには何も残らない）
    • 「💬 チャット」 で会話を開き 「対応完了（AI再開）」（有効な自店スタッフも利用可・チャットの対応開始とAI再開が有効な店舗。他店・他テナント・無効スタッフは不可、全体管理者は可／2026-10-14〜）
  3. AI自動返信が再開
  4. 詳しい手順はスタッフ用マニュアルの「✅ 対応完了にする」を参照
  5. チャットに 「○○さん対応中」が残っているのに、お客様はすでに対応完了（AIは再開済み） の会話は、チャットの 「対応完了（AI再開）」 で片付けられます（チャットの表示が完了になるだけで、お客様へのLINE送信やAIの動きは変わりません／2026-10-12〜）

⚠️ チャットの有効化は順番を守る：「チャットの表示」→「対応開始」→「AI再開」の順に有効にしてください。順番を間違えた組み合わせ（例：AI再開だけ先にON）は、データベース側の約束（制約）で保存時にエラーになり、保存されません（2026-09-05 追加）。また、チャットの表示がOFFの店舗では、AI再開の設定に関係なくLINEの「完了 番号」がそのまま使えます。

  • 操作したい店を選んでから各機能を使う

  • LINE接続（鍵の登録）
  • テナント複製・テナント削除
  • 🧭 初期設定 内の LINE接続パネル
  • 📝 更新履歴（⚙️ お店の設定 の中）：だれが・いつ・何を本番に出したかと、自動の検査・反映の結果（✅合格／❌失敗あり／⏳結果待ち）を新しい順に見る。読むだけで、ここから変更はできない

会計の入力と入れ忘れ（会計機能を有効にした店舗）

  • 予約管理で「来店済み」を記録すると会計入力が開きます。閉じた場合は、予約カードかホームの入れ忘れ一覧から「会計を入力」を押します。
  • 実際の金額を確認し、支払い方法と支払い日を選んで「会計を保存」。予約金額と違う場合は差の理由が必須です。メモは200字以内です。
  • 2回セットなどで今回の支払いがなければ、0円・「先払い済み」で記録します。予約金額と違う場合は理由も選びます。
  • 保存後は「会計 ✓」と金額を表示します。同じボタンから訂正でき、初回の入力者・会計時点の予約金額は保持されます。
  • ホームの「会計の入れ忘れ N件」を押すと、会計開始日以降の来店済み・未取消・未会計が古い順に出ます。LINEの来店コマンドや一括処理で来店済みになった予約も対象です。
  • 入力できるのはオーナー／管理者。店舗が指定された管理者はその店舗だけです。有効な全体管理者も、店舗のスタッフ登録なしで会計を入力できます。
  • 経営タブの「会計済みの売上」は支払い日で集計した実額、「未会計（見込み）」は来店日で集計した予約金額です。別々の行で確認し、合算して実際の売上と扱わないでください。予約金額が未設定の件数は別に表示します。
  • 会計後は予約の店舗・担当・日時を変更できません。コースの金額変更と会計額の訂正は別々の記録です。取消しても会計は消えません。返金はこの段階では扱いません。
  • 会計機能がオフの店舗は入力欄・入れ忘れ・会計集計が表示されません。月末確定の内容を見られるのは全体管理者・オーナーだけです。

月末確定・歩合・調整行（段1b）

  • 「分析」→「🧾 月末確定」を開き、店と対象月を選びます。一番上の「▶ 次にやること」に沿って進めてください。全体管理者・オーナー専用です。
  • 【STEP 1 歩合の設定】赤字の足りない担当・項目を入力します。全員と店の率が揃うと「✓ 設定済み」で閉じます。開けば入力欄と履歴を確認できます。未確認の率を0で埋めず、開始日を確認し「率を追加」「店の率を追加」で保存してください。
  • 【STEP 2 下書きを見る】「下書きを見る」を押し、担当ごとの支払い合計・請求額・入れ忘れ件数を確認します。下の内訳で自己集客、率、教育費、交通費を確認。出勤日数を直すときは理由を入れ「交通費を再計算」を押します。率不足や開始日前入金の警告は先に解消してください。
  • 【STEP 3 確定する】日本時間で月が終わり、下書きと警告を確認してから、開始月から順に確定します。押せない場合はボタン横の理由を確認してください。確定後はこのSTEPに日時・支払い明細・請求明細と「支払いCSV」「請求CSV」が出ます。顧客名は含めず予約番号で照合します。初回の小倉10月分は仁義さんの手計算と照らし合わせます。
  • 金額の見方：交通費／日・クリニック料・月額固定は対象月末の設定を使用。出勤日数は先払いも含む来店日で数え、初月の固定費も満額です。教育費は会社の別払いで、アーティストの支払いから引きません。マイナスの請求額もそのまま記録します。開始日前入金（0円を除く）は会計で入金日か金額を直してください。
  • 確定後の訂正は一番下の「確定したあとに間違いが見つかったとき（調整行）」を開き、理由と任意の訂正元を指定して「調整行を追加」で登録します。元の会計・明細は変えません。アーティストの＋は支払いに加算、請求の＋は請求から差し引き。担当の訂正は元の担当へ−、正しい担当へ＋の2行です。入れ忘れは元の入金日で新規会計し、次月の追加に入ります。
  • 緊急取消の画面はありません。管理者の明示OKを得たサーバー操作で最新月だけ取り消し、理由と元の明細を記録します。
